# Nom du projet


## Description
Courte description du projet (2 à 5 lignes).
Exemple :
Ce projet porte sur la classification de contours de lésions cutanées à l'aide de méthodes d'analyse de données fonctionnelles (FDA). Les contours sont représentés par des fonctions, puis des techniques comme la FPCA et différents classificateurs sont utilisées.

## Structure du projet
- data/ : données utilisées
- scripts/ : scripts R ou Python
- figures/ : figures générées
- results/ : résultats obtenus
- rapport/ : rapport final
